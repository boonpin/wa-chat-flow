# Contacts Management

Contacts are created automatically when messages are received from WhatsApp.

## Per-Contact Controls

- `AI Reply` toggle: ON/OFF
- `Assigned Bot`: specific bot or `Default Bot`

## Search and Filter

- Search by contact name or phone number
- Filter by `All`, `AI ON`, `AI OFF`

## Bulk Actions

1. Select multiple contacts.
2. Use bulk bar to:
- Enable AI
- Disable AI
- Assign a bot
3. Clear selection when done.
