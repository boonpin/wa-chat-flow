# Bots Management

Bots define how AI replies are generated.

## Create a Bot

1. Go to `Bots`.
2. Click **New Bot**.
3. Fill in:
- Bot Name
- AI Provider (`OpenAI` or `Gemini`)
- API Key
- Model
- System Prompt
4. Optional: enable **Set as default bot**.
5. Click **Save Bot**.

## Edit or Delete

- Click any bot from the list to edit.
- Update fields and save.
- Use **Delete bot** to remove it.

## Prompt Tips

- Keep instructions specific to your business tone.
- Add fallback behavior for unknown questions.
- Keep responses concise for WhatsApp readability.
